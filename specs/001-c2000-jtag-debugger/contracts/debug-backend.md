# Contract: DebugBackend (Layer 1)

All implementations (`CcsScriptingBackend`, `SimulatedBackend`) MUST pass `tests/contract/`.
All calls are invoked from the single engine worker thread. Addresses and lengths are in the
core's native address unit (16-bit words for C28x/CLA, bytes for Cortex-M).

```python
class DebugBackend(Protocol):
    def list_probes(self) -> list[Probe]: ...
    def configure(self, probe: Probe, device: str, ccxml: Path | None) -> list[str]:
        """Returns debuggable core names."""
    def connect(self, core: str) -> None: ...
    def disconnect(self, core: str) -> None: ...
    def load_program(self, core: str, image: Path,
                     progress: Callable[[int], None], cancel: Event) -> None:
        """Downloads and verifies; raises VerifyError(address)."""
    def run(self, core: str) -> None: ...
    def halt(self, core: str) -> int:            # returns PC
    def reset(self, core: str) -> None: ...
    def run_all(self, cores: list[str]) -> None: ...
    def halt_all(self, cores: list[str]) -> None: ...
    def state(self, core: str) -> CoreState: ...
    def read_memory(self, core: str, address: int, count: int, width_bits: int) -> list[int]: ...
    def write_memory(self, core: str, address: int, values: list[int], width_bits: int) -> None: ...
    def supports_realtime(self, core: str) -> bool: ...
    def evaluate(self, core: str, expression: str, frame: int | None = None) -> ValueNode: ...
    def assign(self, core: str, expression: str, value: str, frame: int | None = None) -> None: ...
    def callstack(self, core: str) -> list[StackFrame]: ...
    def locals(self, core: str, frame: int) -> list[ValueNode]: ...
    def symbols(self, core: str) -> list[Symbol]: ...
    def ping(self) -> bool:                      # used by watchdog
```

## Errors

| Exception | Raised when |
|-----------|-------------|
| `ProbeNotFound` | no probe / driver |
| `TargetNotResponding` | no power / cable / wrong device |
| `ProbeBusy` | another debugger owns the probe |
| `DeviceSecured` | CSM/DCSM locked (no bypass attempted) |
| `CoreNotAvailable(reason)` | core not released by boot core |
| `InvalidImage(reason)` | not an .out / wrong device |
| `VerifyError(address)` | load verification failed |
| `MemoryAccessError(range)` | inaccessible range |
| `ConnectionLost` | link dropped |
| `EngineMissing` | CCS 20.x not found |

Every method call and result/error is logged (constitution IV).
